# Repository documentation

The canonical user and developer manuals live in `Resources/Help` so the app,
Goblin's documentation tool, and repository readers use the same text.

- [User manual](../Resources/Help/user-guide.md): configure and use the app.
- [How Goblin works](../Resources/Help/concepts.md): understand Gist, AetherMind,
  Autonomy, and the operating baseline.
- [Developer guide](../Resources/Help/developer-guide.md): build, test, modify,
  and prepare a local candidate.
- [Compaction](COMPACTION.md): background summary construction and stable turns.
- [Autonomy](AUTONOMY.md): wake sources, floor ownership, and cancellation.
- [Runtime verification](AUDIT_IMPLEMENTATION.md): runtime invariants and matching
  acceptance probes.
- [Native pipe reference](../Resources/Help/bridge-protocol.md): engine dispatch,
  history paging, settings, and data ownership.

Product identity and packaging defaults belong to `product.json`. Component
licenses and notices remain beside their source and bundled runtime assets.
